6. Integrity Boundary

The current implementation uses deterministic SHA-256-derived signatures to verify whether represented state remains consistent with the material used to generate its signature.

The signature mechanism is an integrity mechanism.

It is not presented as cryptographic authentication.

The current implementation does not claim to provide identity authentication, secure key management, distributed consensus or protection against all forms of adversarial manipulation.

Those boundaries are part of the knowledge status of the release.

---

7. Untimed Semantic Boundary

The implementation does not require timestamps as part of the represented semantic state model.

It therefore demonstrates a form of state representation in which causal relationships can be carried without making a timestamp a required field of the state.

This does not claim that physical time does not exist.

It does not claim that physical clocks are unnecessary for every distributed-system function.

It does not establish that all timing requirements can be removed from computing systems.

The claim is limited to the demonstrated semantic model.
